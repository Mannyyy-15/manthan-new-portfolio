The portfolio is structured as a 5-chapter scroll storytelling journey:

1. **Chapter 01: ABOUT ME (`#evreux`)**
   - The genesis: Born August 2007 in Mumbai, discovering computing, athletic discipline of football #04, self-taught web foundations, formal Computer Engineering background.
2. **Chapter 02: MASTERY (`#rennes`)**
   - Core full-stack architecture: Next.js, React, Node.js, Headless Shopify (Hydrogen), WebGL 3D, and sub-second Core Web Vitals (99/100).
3. **Chapter 03: RECORDS (`#dortmund`)**
   - High-throughput commercial scale: 40+ production launches, co-founding PsmCodes, enterprise SaaS & CRM architectures, high-load payment gateways.
4. **Chapter 04: WORK (`#barca`)**
   - In-depth production case studies:
     - **PieCraft CRM**: Enterprise Order-to-Delivery Pipeline, inventory sync, multi-store dispatch.
     - **Irani Shawarma POS**: Cloud POS with offline-first local synchronization, sub-second order entry.
     - **Avirena Jewels**: Ultra-luxury headless eCommerce with custom 3D configurator and instant checkout.
     - **Mumbai Bazar**: Hyperlocal delivery ecosystem with real-time dispatch and geolocation tracking.
5. **Chapter 05: TRANSFER WINDOW (`#psg`)**
   - Professional milestones (Thepiecraft Marketing, PsmCodes, Beyondsnack), leadership, high-impact enterprise consultation, and direct communication channels.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Mannyyy-15/manthan-new-portfolio.git

# Navigate into project directory
cd manthan-new-portfolio

# Start the high-performance local server
npm run dev
```

Server runs by default at `http://localhost:3000`.

## 🛠️ Tech Stack & Architecture

- **Horizontal Scroll Engine**: GSAP (GreenSock) ScrollTrigger with custom scrub pins and dynamic stroke rendering.
- **Page Transitions**: Taxi.js PJAX routing.
- **Typography**: Authentic typography pairing:
  - `Being-Black` (Bespoke custom vectorized title paths)
  - `Doner` (Display headers)
  - `PP Neue Montreal` (Body typography)
- **Styling**: Pure vanilla CSS design system with custom properties and responsive media queries.
- **Backend / Delivery**: Node.js static streaming server (`server.js`) with aggressive MIME type resolution and zero-cache development headers.
